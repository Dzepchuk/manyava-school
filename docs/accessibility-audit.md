# Аудит доступності

**Дата автоматизованої перевірки**: 2026-07-29  
**Ціль**: WCAG 2.2 AA  
**Статус ручного приймання**: очікує перевірки директором або призначеним
тестувальником.

## Автоматизовані докази

- Playwright + axe охоплюють головну, контакти, сторінки «Про ліцей», новини,
  оголошення, події, документи, прозорість, батьківські й учнівські hub-сторінки,
  протидію булінгу та пошук.
- Перевіряються mobile viewport 320 px, відсутність горизонтального
  прокручування, skip-link, порядок фокуса, доступні назви та `aria-live`.
- `npm run check`, `npm test`, `npm run build` і `npm run test:e2e` є
  блокувальними CI-перевірками.

## Ручний протокол

- [ ] Пройти всю основну навігацію лише клавіатурою.
- [ ] Перевірити visible focus і відсутність keyboard traps.
- [ ] Перевірити VoiceOver: головна, новина, документ, пошук і `/admin/`.
- [ ] Збільшити масштаб браузера до 200% на desktop і mobile.
- [ ] Увімкнути `prefers-reduced-motion: reduce`.
- [ ] Перевірити контраст тексту й станів фокуса за реальних моніторів.

Ручний аудит не можна позначати завершеним лише на підставі axe: автоматизація
не перевіряє зрозумілість альтернативних описів, якість читання скринрідером або
логічність усіх переходів.
