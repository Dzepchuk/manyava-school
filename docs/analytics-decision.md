# Рішення щодо аналітики

**Рішення MVP**: не підключати аналітику.

## Обґрунтування

- Для виконання основних функцій сайту поведінкове відстеження не потрібне.
- Відмова від сторонніх scripts зменшує ризик профілювання дітей, кількість
  cookies, мережеві запити та час завантаження.
- `src/data/site.yml` містить `analyticsEnabled: false`.
- Сайт не показує cookie banner, оскільки не встановлює аналітичні cookies.

Будь-яке майбутнє підключення аналітики потребує окремого рішення з описом мети,
переліку даних, строку зберігання, правової підстави та перевірки впливу на
приватність дітей.
