# Тестовий сценарій ролей і публікації

Статус: очікує налаштування production GitHub OAuth та Netlify preview.

## Передумови

- окремий акаунт технічного адміністратора з роллю GitHub `Admin`;
- окремий акаунт директора з роллю GitHub `Write`;
- MFA увімкнено для обох акаунтів;
- branch protection і required checks налаштовано для `main`;
- GitHub OAuth provider підключено в Netlify без збереження секретів у Git.

## Publish-preview-approve

- [ ] Директор входить у `/admin/` власним GitHub-акаунтом.
- [ ] Створює тестову новину з дозволеним фото, alt і відомостями про права.
- [ ] Зберігає чернетку; production та Pagefind не змінюються.
- [ ] Netlify створює preview, а перевірки завершуються успішно.
- [ ] Директор переглядає preview і публікує матеріал.
- [ ] Новина з’являється у production; зафіксовано тривалість сценарію.

## Межі ролей і відкликання

- [ ] `Write` може редагувати контент, але не керувати доступом, OAuth чи secrets.
- [ ] `Admin` додає тестового редактора з мінімальними правами.
- [ ] `Admin` відкликає доступ; повторний вхід і push для редактора недоступні.
- [ ] Спільні облікові записи не використовувалися.

## Conflict і revert

- [ ] Паралельні зміни одного запису створюють видимий Git conflict.
- [ ] Conflict вирішено до merge без втрати перевіреного контенту.
- [ ] Опублікований навчальний commit відновлено через `git revert`.
- [ ] Production повернувся до попередньої версії; зафіксовано час відновлення.

Результат: очікує зовнішнього налаштування
